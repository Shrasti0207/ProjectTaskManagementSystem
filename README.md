# Project Task Management System
This is a Spring Boot application for managing projects and tasks. It allows users to create, update, retrieve, and delete projects and tasks while handling various exceptions globally.

## Features
- Create, retrieve, update, and delete users
- Create, retrieve, update, and delete projects
- Create, retrieve, update, and delete tasks
- Update task status
- Get tasks by filters (status, priority)
- Get tasks by project

## Technologies Used
- Java, Spring Boot, Spring Data JPA
- H2 Database (for testing)
- Maven (build tool)

## How to Run
1. Clone the repository: git clone https://github.com/Shrasti0207/ProjectTaskManagementSystem.git
2. Configure database
3. Build and run the project
